# РеестрПро — мобильное приложение

React Native (Expo) + axios. Все данные берутся с backend `/server` через HTTP.

## Установка

```bash
cd mobile
npm install
```

## Настройка API_URL

Откройте `mobile/config.js` и впишите IP компьютера, где запущен сервер:

```js
export const API_URL = 'http://192.168.1.42:3000/api';
```

Узнать IP на Windows:

```powershell
ipconfig
```

В строке `IPv4-адрес` вашего Wi-Fi подключения.

## Запуск

```bash
npm run start
```

В консоли появится QR-код. Установите на телефоне **Expo Go** (Google Play / App Store), и отсканируйте QR.

> Телефон и компьютер должны быть в одной Wi-Fi сети.
> На Windows может потребоваться разрешить порт 3000 в брандмауэре.

## Тестовый сценарий «на двух телефонах»

1. На ПК: `cd server && node server.js`
2. На ПК: `cd mobile && npm run start`
3. Телефон A (Спартак): Expo Go → отсканировать QR → войти `admin@test.com` / `admin123`.
4. Телефон B: то же самое.
5. На телефоне A создать водителя, контрагента, заказ.
6. На телефоне B открыть «Все заказы» → потянуть список вниз → увидеть новый заказ.
7. Зарегистрировать водителя (на любом телефоне через «Регистрация водителя»), войти под ним → видны только его заказы.

## Что хранится локально

В `AsyncStorage` лежит **только JWT-токен** (чтобы не вводить пароль при каждом запуске).
Бизнес-данные (водители, заказы, фото) **не хранятся** на телефоне — только на сервере.
