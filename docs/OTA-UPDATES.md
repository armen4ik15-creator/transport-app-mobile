# OTA-обновления ReestrPro (без нового APK)

## Как это работает

- **APK** — устанавливается один раз на телефон (сейчас базовая сборка **v1.3.8**).
- **OTA (EAS Update)** — JavaScript/UI/API-логика публикуется на сервер Expo и подтягивается при запуске приложения.
- **Runtime `1.3.8`** — фиксированный идентификатор. Пока он не меняется, новый APK не нужен.

## Публикация изменений (для разработчика)

```bash
cd C:\work\mobile

# 1. Поднять версию в app.json (только поле "version", НЕ runtimeVersion)
#    например: "1.3.9" → "1.4.0"

# 2. Проверка типов
npx tsc --noEmit

# 3. Опубликовать OTA
npm run update:production -- "Краткое описание изменений"
```

Пользователям: **полностью закрыть приложение и открыть снова** (2 раза, если обновление большое).

## Когда нужен новый APK

| Можно через OTA | Нужен новый APK |
|-----------------|-----------------|
| Экраны, тексты, формы | SSL, DNS, Kotlin/Java |
| API-логика, таймауты | AndroidManifest, разрешения |
| Исправления багов в JS | Новые native-библиотеки |
| Скорость, кэш, UX | Смена `runtimeVersion` |

При native-изменениях:
1. Поднять `runtimeVersion` в `app.json` (например `"1.4.0"`).
2. Собрать APK: `cd android && gradlew assembleRelease`.
3. Раздать APK всем один раз.

## Проверка на телефоне

На экране входа: **«Версия приложения: X.Y.Z»** — это OTA-версия из `app.json`.

Если OTA не приходит:
- Убедитесь, что установлен APK **v1.3.8+** (не старый v1.3.1).
- Закройте приложение из списка недавних и откройте снова.
- Проверьте интернет (OTA качается с `u.expo.dev`).
